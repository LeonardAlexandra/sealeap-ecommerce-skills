# OZON 细分市场筛选与进入评审：判断与验收

输出候选评分表、原始样本列表、纳入/排除原因、proxy_metrics、market_metrics、单位经济及履约结论、试销约束。不得用总评论数推断月销，也不能因暂无 MPstats 宣布无分析能力。

无市场规模数据时，market_size / sell_through / revenue_share 置 UNKNOWN；可比样本和成本充分仍可提出有限试验，不能称“已验证蓝海”。只有大类数据没有目标规格样本时 HOLD。

回归重点：轻小件在假定有效证据下可小额试验；低价负贡献 NO-GO；本土热销但跨境体积重超限 NO-GO；报价缺失 HOLD。

通用规则及输出结构见 [多源证据合同](data-contract.md)；缺失字段不得填0或用行业均值暗中补齐。
