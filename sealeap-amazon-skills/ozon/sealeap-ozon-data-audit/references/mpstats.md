# MPstats 可选增强

先按 [多源证据合同](data-contract.md)与[适配步骤](adapters.md)判断现有数据能支持什么。没有 MPstats 仍可验收自家数据、建立竞品池、描述价格带、核算利润和物流。
仅在需要第三方市场估算时请求对应 OZON 报表；不得把评论、排名或卡价伪造成订单/收入。外部销量/金额标 ESTIMATE，内部已核自家账单才可 FACT。
用 [官方 Ozon API](https://mpstats.io/integrations/analytics-oz/)核对端点和字段；实际发现工具后再调用，令牌仅走私有环境和请求头。401/403停止，202不是完成，429有限退避。不得自动绑定账户或安装软件。
记录原件哈希、SKU粒度、时间、币种/单位、FBS开关、分页及样本分母。能力存在、文档可读、返回成功均不等于数据通过审计。
旧名称数据审计包保留只读 API 探针和旧日序列校验器；它们不会自动转换通用 Schema。
