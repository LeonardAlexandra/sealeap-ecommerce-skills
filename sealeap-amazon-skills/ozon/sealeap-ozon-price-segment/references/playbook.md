# OZON 价格带与规格机会：判断与验收

输出规格×数量×价带表、原价格列、单位化公式、样本数/排除数、成本底线、可试范围。中位数不是截尾平均；两件装1000与单件600仅在同规格时可比较单位价500与600。

GO 仅为具备正贡献压力情景的限定试价建议；完整成本证明低于底线 NO-GO；币种/数量/收入映射未知 HOLD。前台价格带描述就绪可以交付，即使试价结论 HOLD。

MPstats 的价格/销售分箱可选加入；先核实际销量、计费基础、样本覆盖，不使用最新价×历史销量捏造历史收入。

通用规则及输出结构见 [多源证据合同](data-contract.md)；缺失字段不得填0或用行业均值暗中补齐。
