# OZON 竞争格局与可比商品池：判断与验收

必需：可比用途/规格、SKU、样本选择、目的地/时间与至少一个已核价格。seller_id 缺失只阻塞卖家聚合，不阻塞单品描述；销量缺失只阻塞销售份额，不阻塞竞品池。

GO/HOLD/NO-GO 的 decision_scope 必须写“竞品池可用于下一步比较”，不能暗示商品已可上架。无可比样本 HOLD，明确规格不匹配的条目 NO-GO（排除），通过者 GO 仅指比较可用。

输出冻结竞品池、纳入排除、卖家/品牌双视图、已知/未知履约、评论代理、份额分母及限制。评论多是历史互动线索；新增评论、库存变化和排名变化不直接兑换销量。

通用规则及输出结构见 [多源证据合同](data-contract.md)；缺失字段不得填0或用行业均值暗中补齐。
